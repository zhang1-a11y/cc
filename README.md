## 五篇定义

- [01 编年型](01-信息图形数据逻辑/01-编年型信息图形概念定义.md)：事件／状态与时间关系。
- [02 层级型](01-信息图形数据逻辑/02-层级型信息图形概念定义.md)：从属、包含、分支或明确等级。
- [03 编目型](01-信息图形数据逻辑/03-编目型信息图形概念定义.md)：按共同属性分类的对象集合。
- [04 字母表型](01-信息图形数据逻辑/04-字母表型信息图形概念定义.md)：字符序列与词条的对应。
- [05 地理图形](01-信息图形数据逻辑/05-地理图形信息图形概念定义.md)：位置、区域、路径与空间关系。

A 定义数据关系与字段；B 说明统计图形和计算边界；C 解释点、线、面、体、符号、色彩及文字；D 组织数据与信息层次；E 设计阅读路径、转折与结论。没有数值统计的作品，B 项应如实说明，不能强加计算。

## 数据逻辑与表现类型

| 维度 | 回答的问题 | 关系 |
| --- | --- | --- |
| 数据逻辑 | 数据为何按这种关系组织 | 一件作品可以组合多种逻辑 |
| 表现类型 | 通过怎样的图表、文字、符号和叙事阅读 | 与数据逻辑交叉对应 |

例如时间轴常用于编年数据，混合型可以同时承载编年与编目。PDF 第 36—37 页明确标注“编年图＋编目混合图”；具体画面仍须核验。字母序不等于数量顺序，树状结构也不等于时间顺序。

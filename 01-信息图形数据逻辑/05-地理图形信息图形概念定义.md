# 05 地理图形信息图形概念定义

> 来源状态：已结合用户 PDF 文字与本轮归档原图更新。具体图文记录见文末链接；未归档页面、原作出处及模糊数值仍按来源记录核对。

## A 基本的数据逻辑

本质是**带位置或空间关系的数据**：点（经纬度／地点）、线（路径／网络）、面（行政区／地理区域）及其属性、时间和坐标参照。空间邻近、包含、距离、方向与连通性需要分别识别；地名相同不代表同一地点，行政区边界也随年份变化。数据应保存地理标识、坐标系、边界版本与采集口径。并非所有标地点的插画都有可分析的地理尺度。

**度量与示意的区别**：地理坐标型应保留 `geo_id、geometry、crs、boundary_year、metric、value、unit、time、source`；路线示意型可保留节点、连边和方向，优先保证连接关系，并明示“不按实际距离绘制”。某些示意地图只表达拓扑，不能从线段长度读取距离。

**课件对照**：第 17 页确定地理图形的教学类别，第 18—21 页须核对具体空间关系。不能由标题判断它们都是精确投影地图或都有比例尺。

**外置符号地图的补充（C001）**：地点指标按稳定地理键聚合时，地理锚点与展示符号可分离。地理表保留真实坐标、空间单元和版本，布局表另存符号位置及标签。引导线连接同一地点身份，不会把展示位置变成新的地理坐标。企业营收按总部归属汇总时，须明确归属版次；营收归属不等于该地点的GDP或本地生产。

## B 统计图形与计算

地点数量可做点图或聚类；区域值可做分级设色；流向和路径可做流线图；密度需说明分母（面积、人口等）与估计方法。行政区总量的分级设色容易让大区域压过小区域，比率与总量要区分；符号面积若表示数值，半径须按面积关系计算，即半径与数值平方根成正比。可计算距离、区域汇总、空间连接与变化，但必须说明地图投影、空间单元和聚合方法。颜色分级边界、缺失区域和零值分别编码。

| 数据问题 | 图形选择 | 必须核对 |
| --- | --- | --- |
| 在哪里 | 点位图、符号地图 | 坐标、遮挡、位置精度 |
| 区域之间比率如何 | 分级设色图 | 同口径分母、分级边界、缺失值 |
| 区域总量多少 | 比例符号地图 | 符号面积与数值成正比，保留图例 |
| 从哪里到哪里 | 路线图、流向图 | 起终点、方向、线宽单位和是否按真实路径 |

人口密度 = 人口／面积，人均值 = 总量／人口；更换空间分区或汇总尺度可能改变比较结果，结论需绑定空间单元。点密度图“一点代表若干对象”与精确点位图“一点是一个实际地点”必须区分。

**外置圆的量尺补充（C001）**：符号可以移到地图外避让，面积比例的约束仍相同。若v为量值，以最大圆半径r_max标定，r_i = r_max × √(v_i／v_max)。原图若没有尺寸图例，只能记录“随量增大”，不能把外观判断写成已确认的面积比例。精确值用直接标签补充；没有箭头、流量单位或路径语义的引导线不归为流向图。

## C 视觉编码

点表示地点，线表示实际路线／概念连接，面表示区域范围；流线宽度可编码流量，但方向箭头与起止点仍要可辨。色相区分类别，顺序明度表示连续高低，发散色适用于有意义的中心值。地图底图降低对比度以突出数据层；图例、比例尺、方向、数据单位与投影／示意声明按需求补齐。3D 高度会受视角遮挡，若用来表示数值，须保留可读的精确值。图标或地标插画不可遮盖数据点，也不应冒充按比例绘制。

**位置与规模分工（C001）**：地图小点可以只表达地点存在，大圆表达地点属性，引导线表达身份对应，直接文字表达精确量值。小点不自动代表一个企业或一个观测对象。强调色与区域底色需要分别解释，不能因为都用白色便认为采用同一指标色标。

## D 数据／信息架构

先定义空间范围与层级，再建立地理键到数据记录的映射，核对无法匹配、重复匹配、边界变化及离群坐标。信息层次为范围与读图法 → 主地图 → 地区详情／局部放大 → 统计对照 → 来源及地图口径。高密度地点需分面、缩放或列表，不可仅靠标签重叠解决；小区域可配局部插图或同尺度统计图。

**架构落地**：地理表与指标表通过稳定地理键连接，保留匹配失败清单；一个地区多时点采用复合键。总量、比率和分布分别建字段，不在显示时临时混算。地图旁的排名表可补充小区域读数，并共享颜色与单位。

**双坐标落地（C001）**：在地理表之外维护以geo_id连接的布局表，分别保存anchor_x／anchor_y与symbol_x／symbol_y、radius、label_side。底图使用透视或其他变换时，地理锚点同步变换；避让只移动展示符号与标签。区分“全部存在点”和“重点量值对象”两组范围，原始地点清单缺失时不补造背景点。

## E 视觉叙事架构

用全局地图建立方位，再引导到热点、异常或路径，最后回到区域间可比的结论。地图上的视觉大小不等于指标重要性；从地理共现推论社会原因须有独立证据。路线叙事可沿空间移动，区域对照则可按同一指标和统一分级依次比较。结尾说明地图不能回答的因果或个体层问题。

**组合比较的叙事边界（C001）**：可按“单城主角 → 多城比较 → 地图定位 → 个例解释 → 城市组合”展开，但从单个都市区改为三城合计时必须显式交代比较单元变化。总部迁址是指标归属变化的解释案例，单期图本身不能计算城市增长率或验证长期趋势。以上是版面编排分析，不是读者实验结果。

## 判别与更新

若改变地点或空间邻接就改变主要结论，地理逻辑居于核心；如果地图仅是背景插画，则需另辨主逻辑。新增案例时记录投影／边界、聚合单元、归一化与颜色分级，并链接案例记录。

## 共同设计与同步更新

**导论方法补充（2026-11-23）**：《信息图形设计导论(1)》第31—45、86—89、109—118页支持从读者任务出发，先组织数据，再论证编码、叙事与探索。本类优先检验读者能否定位、辨认连通或比较地点属性；地理邻近、符号大小与因果解释分别核对。论述使用“判断—证据—机制—限制”，分析者走查与实际实验分开。详见[执行框架](../02-信息图形类型案例/案例登记与更新规范.md#analysis-framework)和[新导论页码对照](../02-信息图形类型案例/PDF对照与案例索引.md#intro-methods)。下文原课件页码仍指73页《第三讲-信息图形类型学》。

根据课件第 40、43、69—70 页，先确认读者任务和数据结构，再选择视觉形式；D 应给出“概要 → 细节 → 来源”的层次，E 决定主线和可自主探索的入口。结构组织与叙事路径分别检查。图标的语义作用、统计作用与装饰作用不得混为一谈；文字、图例与来源不因追求简洁而删除。

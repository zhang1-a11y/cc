## 记录单位与来源

P编号为课件实际页序，I编号为提取图序号；不得把页内印刷页码与实际页序混用。保留提取包原路径、像素尺寸和SHA-256。原图保留字节，不以缩略图替换。新增独立用户图片可采用C001等稳定编号。

外部参考采用单独来源序列。本次W001、W002为外部词云参考，登记项目、固定版本、原文件路径、字节数、尺寸、SHA-256、关联源码和许可；不得写成用户课件原图，也不复用C编号。原图与源码的历史版本对应未确认时，应分别标注图像观察、实现核对和未知参数。

同一作品的多个版式分别建图文记录，注明版本关联，不把它们当作独立数据证据。一页多图分别记录，一图跨类型时指定主要保存位置，其他类型通过链接引用。

标题可用本库检索描述，但须区别于正式原作标题。作者、原始日期与数据出处未知就写未知；课件署名、品牌标识与真正作者不能混同。

## 完整分析的记录要求

每篇包含原图嵌入与来源、直接观察、A数据逻辑、B统计图形与计算、C视觉编码、D数据／信息架构、E视觉叙事架构、边界与待核实项、类型与01定义回链。没有数值统计则如实说明；无法辨认数值或图例则保留待核实。

观察指实际看见的元素与位置；数据结构与阅读路径属于分析解释；改进办法属于建议。原课件分类与实际主逻辑冲突时，两者都记录，不强行改写画面。

## 从读者任务开始的分析顺序

以下步骤是本库对《信息图形设计导论(1).pdf》的操作化整理，并非课件原有的逐项评分表。页码采用该119页文件的实际页序；与原73页《第三讲-信息图形类型学》分别记录，详见[双来源对照](PDF对照与案例索引.md#intro-methods)。

1. **界定问题与受众**：用一句话说明作品帮助谁回答什么问题，在何种媒介、尺寸和阅读情境下使用。按“展示、比较、组织、关联”标记主要任务，再写2—4个可核查的读图问题，例如“哪个对象最高”“何时发生转折”。依据第21、31—45、86页。
2. **登记证据与数据口径**：分清画面上可读的事实、原始数据来源和分析者的解释。记录对象、字段、时间／地域范围、样本、单位、分母、缺失与筛选规则；同时问“展示了什么、遗漏了什么”。数据—信息—知识—智慧是第25页的讨论框架，不意味着一次视觉转译就自动产生知识或正确决策。
3. **先判01，再标02**：先从编年、层级、编目、字母表、地理五种数据组织关系判断主逻辑与辅助逻辑，再注明17种表现类型中的主标签和交叉标签；若采用 ISOTYPE 方法，另标基础设计方法 `ISOTYPE`，不以此替代主数据逻辑或表现类型。第48页与68—84页对应不同分类层次；照片、三维、词云等外观不能代替数据关系判断。保留原来源标签，不因分析结论改变归档文件夹。
4. **完成A—E机制拆解**：A解释关系如何成立；B解释统计口径和可比性；C逐项连接“数据变量—视觉通道—图例／量尺”；D解释信息如何分组、导航与展开；E解释观点如何进入、推进和收束。要说明每项选择如何帮助读者完成第1步任务，而不只罗列颜色、形状和版式。
5. **评估表达与探索的平衡**：指出标题或强调所给出的主张，以及读者能自行核查、比较和发现的信息。按“概要—主要数据—内部细节—来源”描述层次，保留必要上下文与导航。依据第109—118页。
6. **重建流程并检验**：按“收集清洗—建立数据集结构—编码与版式—关联与呈现”写可执行步骤，再检查数值、量尺、标签、阅读任务和适用边界。此顺序来自第89页。看不见的原作软件、参数和作者意图不作事实填写；建议的重制方法明确标为分析者方案。

### A—E如何衔接

| 分析层 | 必须回答 | 论述中应给出的证据 |
| --- | --- | --- |
| A 数据逻辑 | 哪些对象通过什么关系组织，为什么以此为主逻辑 | 时间键、父子边、分类字段、字符序或地理键；指出不能据外观确认的项 |
| B 统计图形与计算 | 什么值能比，比较基于什么口径 | 分母、单位、共同尺度、聚合与归一化；无统计时如实写明 |
| C 视觉编码 | 哪种视觉差异承载哪项数据差异 | 位置、长度、面积、体积、色彩、符号或文字的具体映射；区分数据、语义、分组、导航和装饰 |
| D 信息架构 | 数据关系怎样变成可查找、可比较的页面 | 概要、模块、字段顺序、图例、详情与出处；区分数据层结构和版面层次 |
| E 视觉叙事 | 作品提出什么主张，读者如何检查它 | 标题、入口、比较节点、注释、转折与结尾；编排推断不写成实际眼动 |

## 论述框架：让判断有证据和机制

总论按“问题与主要判断 → 数据及分类依据 → A—E机制 → 效果与代价 → 制作及验证 → 可迁移条件”展开。每个分析段落使用：

**提出判断 → 指出具体画面或来源证据 → 解释图形如何转译数据、支持思考 → 说明限制或另一种解释。**

例如，不能只写“颜色丰富，层次清晰”。应写明哪些对象被同色归组，图例把颜色映射到何种类别，这是否减少来回查找，以及是否仍需要文字标签。该例是论述方式示范，不是对某张已收录图片的分析。

结论使用与证据相称的动词：“画面可见”用于观察，“据此推断”用于解释，“重制时可”用于建议。作品目的和阅读路径没有作者说明或读者实验时，应写“可能支持”“编排意图可解释为”，不写成已证实的心理效果。相关性、邻接、时间先后或箭头都不能独立证明因果。

### 形式与功能的评估

第38、44—45页强调功能约束形式，同时保留多种编码选择。先比较哪个方案让目标任务更容易完成，再讨论风格。

| 维度（第94—99页） | 分析问题 |
| --- | --- |
| 抽象／具象 | 概念编码是否需要学习；具象图像是否帮助识别或遮蔽精确比较 |
| 朴素／修饰 | 修饰是否解释内容、组织信息或帮助记忆；是否占据关键数据空间 |
| 致密／稀疏 | 信息密度是否适合媒介；标签能否辨认；留白是否帮助分组 |
| 多维／单维 | 每个维度是否服务主要问题；是否缺少必要的比较条件 |
| 创新／通用 | 新形式的读法成本是否有明确收益；是否需要图例或示例 |
| 简洁／深度 | 表面是否清楚，同时允许读者继续核查细节和上下文 |

这是六组取舍，不是“越简、越稀疏越好”，也不把轮盘大小当作统一质量分数。第100—102页的数据／油墨比用于检查非必要表达，未实际测量时只作定性讨论；不能为提高比例删除单位、图例、必要注释或出处。第113—117页支持简化形式、组织复杂信息，而不是任意删去关键数据。

### 检验与证据状态

- **静态核查**：检查数字转录、单位、分母、刻度、面积／体积关系、色标、来源、未知项和相对链接；判断结论是否超出数据覆盖范围。
- **任务走查**：用最初的读图问题检查是否需要不断寻找、记忆、心算、重排或跨图比较。将可通过对齐、排序、直接标签或统一尺度减少的操作具体写出，依据第39—44页。分析者走查不等于用户测试。
- **实际读者测试（如有）**：登记参与者、任务、版本、时间与正确率／错误类型；若做眼动或记忆测试，另记设备、程序和时间间隔。第88页提到眼动、主题／参数／强调／事实与评论问题，以及5分钟与2周的记忆检查；它不是本库已完成的实验，也不是所有项目必须照搬的指标。
- **可迁移经验**：最后填写“适合什么数据与任务—需要什么条件—什么情况下失效—如何重制和复核”，避免把单例的风格偏好写成普遍规律。

## 新增案例时同步更新

以下同步流程适用于用户要求完整分析的新增或纠错任务；“仅加入图片”按前述例外执行。本次方法更新只修改已有文档。

1. 将原图与同编号说明放入已有对应类型文件夹，核对来源、单位、图例及未知项。
2. 在本类 README 的案例表加入该图文配对；用案例支持、限制或修订原则，标出反例。
3. 核对01相关定义的 A—E 和文本案例链接；有新证据或边界变化时修订，原则未变时记录已核对，避免无意义重写。
4. 更新02总索引、来源对照、数量和修订日期。
5. 同一次提交中检查图片、Markdown、相对链接、锚点、文件计数与01无图约束。

同一个案例有多种逻辑或表现方式时使用标签和交叉链接，不复制成多个无关案例。目录归档完成不等于原始数据已复核。

## 分析与完成状态

原《第三讲-信息图形类型学》第43页与新《信息图形设计导论(1)》第89页均给出从收集清洗到结构、编码版式及关联呈现的流程。受众、读图任务、概要与细节、事实与评论按各自来源页码核对，不能互换页码。

已看清的构图可以完成结构分析；未辨清的微小数值、作者及历史数据来源保留未知。没有进行眼动或记忆实验时不填写实验结果。仅归档图片保留“仅原图归档，未分析”，不计入已完成A—E的数量。完整分析状态分为“来源已登记／画面已核对／A—E已分析／原始数据待复核／原则已同步”。

上述为每次新增或纠错的执行规则；当前没有后台自动分析机制。

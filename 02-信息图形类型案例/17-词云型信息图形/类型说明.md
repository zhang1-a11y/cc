# 词云型信息图形（Word Cloud / Tag Cloud）

更新日期：2026-11-20。类型分析依据本目录两幅已核对原图和开源实现；不把本次新增类型归称为课件原有第17类。

## 定义与边界

以可读词项为图形标记，将词频或其他已定义权重映射到字号等视觉属性，形成文本内容的概览。Tag Cloud 也可处理人工标签的使用次数，而不限于自然语言正文。

统计型词云必须有“词项—权重”的可追溯关系。若只由编辑挑词并调整大小，应标为编辑型关键词拼贴；它可作主题表达，但不能宣称是频率统计。文字网络还包含边与关系，字母表依赖字符序检索，两者不能仅凭文字外观与词云混同。

## A 基本的数据逻辑

先识别记录单位：

| 数据层 | 最小字段 | 回答的问题 |
| --- | --- | --- |
| 原文／样本 | document_id、text、source、time、group | 收集了哪些文本，来源和范围是什么 |
| 词项归并 | term_id、raw_term、normalized_term、rule | 大小写、词形、别名如何归为同一对象 |
| 统计结果 | term_id、count、document_count、weight、metric | 每词出现多少次、覆盖多少文档或获得多少权重 |
| 展示配置 | term_id、font_size、color_group、x、y、orientation | 各字段如何转成图形；布局坐标是否有意义 |

本库五类中，W001、W002 按词项归并建立目录，故主逻辑为编目；数值权重排序为辅助关系。只有实际按日期分组才增加编年逻辑，只有真实父子类别才增加层级逻辑，只有按 A—Z／拼音检索才增加字母表逻辑，只有绑定地点才增加地理逻辑。不能凭词云外形强行归类。

## B 统计图形与计算方式

### 1. 先定义统计口径

- 词频：某规范化词项在清洗后文本中出现的次数，同一文档重复出现可多次计入。
- 相对词频：该词次数／同一清洗口径下全部保留词项次数；跨组比较须统一分词、过滤和分母。
- 文档覆盖：含该词的不同文档数；除以有效文档总数得到文档覆盖率。只有一人对应一篇且去重已验证时，才可解释为提及人数。
- 其他权重：如模型相关度、人工评分，应记录算法／量表、范围和含义；不能改称词频。

中英文分词、停用词、数字、同义词、多义词、专名、大小写和单复数处理都会改变结果。短语与单词混合时交代是否允许重叠计数；若启用实现内置搭配识别，输出不是未经处理的原始单词计数。

### 2. 从权重到字号

可自定义线性、平方根或对数压缩映射，但应明确函数、范围和最小字号。对于自行设计的线性映射，可使用：

`字号 = 最小字号 + (最大字号−最小字号) × (权重−最小权重)/(最大权重−最小权重)`。

该式为方法示意，不是两幅历史 PNG 的已确认生成公式。权重全部相等时须单独设置统一字号，不能除以零。

相同字号的不同词因词长和字形而占据不同面积；字号增大也会同时改变宽高。因此“字形占地面积正比词频”“字号两倍即词频两倍”都不能默认成立。

### 3. 实现核对

所读 word_cloud 实现会按权重排序、截取 max_words、按最大权重归一化，再依据 relative_scaling 调整候选字号；找不到空间时还可能旋转或缩小。默认配色函数不自动读取词频或语义类。故统计权重与最终字形是有约束的映射，不是无损量尺。

## C 视觉编码

| 元素 | 可编码内容 | 本类型的设计与核对重点 |
| --- | --- | --- |
| 点／节点 | 以一个词项作为一个可辨认标记 | 一词一对象；重复渲染不额外解释为新增观测 |
| 线 | 通常无数据边；可作注释引导 | 不能凭词间邻近虚构共现连线或关系强度 |
| 面／轮廓／留白 | 排版区域、主题形状或类群容器 | 轮廓若来自掩膜，应说明其图像语义及可放词空间 |
| 体 | 通常不使用定量体积编码 | 立体字、透视或阴影不能代替词频量尺 |
| 文字／符号 | 词项身份、短语和注释 | 中文使用完整字库，长短词均保留可读性 |
| 字号／字重 | 明示的权重或编辑强调 | 交代函数与上下限；不同字重会改变显著性和占地 |
| 色彩 | 类别、数值或装饰 | 绑定字段并提供图例；不用红绿自动代称情绪极性 |
| 位置／方向 | 一般用于填充、避让与阅读 | 无轴、无算法说明时，不把中心位置或距离解释为相关性 |

优先保证可读和语义一致。类别配色还应提供文字说明；需要严格排序或精确差值时，配套同口径条形图和数据表。

## D 数据／信息架构

底层把原文、规范化词项、统计结果和布局分开保存。保留原文定位信息，以便从一个词追溯到原句；清洗前后词数、去重方式和缺失文本处理应可检查。

展示采用“主题／问题 → 语料范围与统计口径 → 词云概要 → 高频词表／原文摘录 → 方法与来源”。比较多组时使用相同字体、画布、过滤规则及共同权重尺度，不能把每组各自归一化后的最大词直接比较为同量。

W001 不具备语义类别图例，W002 配色规则在源码中而未在原图中显示；本库在文字说明补足两者边界，不修改原图。

## E 视觉叙事架构

大词提供显著入口，中小词提供主题线索；分组颜色可补充第二条阅读路径。最后用词频表、原文与说明收束，避免从孤立词语推导作者立场、赞成比例或因果关系。

否定、讽刺和引语上下文在词云中容易丢失。例如出现某个“问题词”只能说明它被纳入统计，不能直接证明文本支持该问题。读图效果只能提出评估建议；未开展实验时不填写阅读速度或记忆效果。

## 可复用制作流程

1. 明确读图任务和语料来源，记录纳入、排除、时间和样本单位。
2. 分词并清洗；建立停用词表、术语表、大小写／词形归并规则，抽样核对原文。
3. 输出词项统计表，选择词频、文档覆盖或其他权重；检查重复记录和分母。
4. 明确字号映射、最大词数、最小字号、颜色字段和颜色图例。
5. 使用词云排版生成布局；中文提供字体，保存随机种子、尺寸、方向比例、字体和工具版本。若采用 generate_from_frequencies，预先完成清洗与统计。
6. 对照统计表检查大词、被过滤词、漏词和排版缩小；多组比较保持共同尺度。
7. 导出图片及可检索文本／数据表；记录版权来源和处理参数。固定种子可帮助复现布局，但跨版本和字体环境仍须核对。

本流程是基于开源实现提炼的方法，未将词云记为前次所读 RAWGraphs 应用的内置图表。

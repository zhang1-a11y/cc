# 词云型信息图形（Word Cloud / Tag Cloud）

本文件夹收录 2 张外部开源项目参考原图及 2 篇同编号分析。更新日期：2026-11-20。W001、W002 为本库外部词云参考编号，不代表课件页序，也不计入独立用户图片 C 序列。

## A 基本的数据逻辑

以规范化后的词项为对象，以出现次数、文档覆盖数或明确说明的权重为属性。在本库五类逻辑中，两例均按“词项归并的编目主逻辑＋权重排序辅助关系”理解；字号差异不是父子层级，出现文字不等于字母表索引。

## B 统计图形与计算

词云以字形及字号突出词项权重，支持文本概览。先分词、清洗和归并，再统计；词频、提及人数和人工重要性分值是不同口径。字号还受到缩放函数、词长、字体和排版避让影响，不能从图中直接反算精确频率。

## C 视觉编码

文字标识词项，字号形成权重强调；颜色只有绑定并说明分类或数值规则时才具有统计含义。两词靠近不自动表示语义相关，横竖方向不自动代表正负倾向。轮廓、背景和留白通常承担构图作用。

## D 数据／信息架构

原文及文档 ID → 规范化词项 → 计数／权重表 → 显示映射与布局。展示时保留主题、语料范围、统计口径、过滤规则、图例和来源；需要精确比较时附词频表或条形图。

## E 视觉叙事架构

以大词提供入口，再浏览中小词和类别，最后回到原文验证上下文。词云适合概览，不单独证明观点、因果、情绪或样本代表性。

## 从本组案例归纳的方法与边界

W001 展示矩形词云和字号显著性；W002 在词频布局上叠加人工词类配色。前者的多色不能直接解释为类别，后者的红绿也不是自动情感计算。两例均没有可供精确读数的量尺。

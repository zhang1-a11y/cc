# 混合型信息图形（Mixed Charts）

本文件夹收录 3 张用户课件原图及 3 篇同编号说明文档。更新日期：2026-11-20。案例按原课件归类保留，实际主逻辑或边界在逐图说明中注明。

## A 基本的数据逻辑

由多类指标或多种表现组件共同回答一个主题问题。

## B 统计图形与计算

组合图表、单位符号、文字与图解；各组件保留自己的分母、单位和时间。

## C 视觉编码

符号语义与数量映射分开，跨模块同对象同色同符号。

## D 数据／信息架构

主题概览、分问题模块、细节与来源分层。

## E 视觉叙事架构

先给主题入口，再由主图证据进入解释与细项。

## 从本组案例归纳的方法与边界

P022-I01 展示异单位模块并置；P059-I01 明确一枚5%；P061-I02 使用共同人口基准。混合不降低数据口径要求。

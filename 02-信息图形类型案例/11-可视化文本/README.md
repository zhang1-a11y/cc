# 可视化文本（Visualized Text）

本文件夹收录 2 张用户课件原图及 2 篇同编号说明文档。更新日期：2026-11-20。案例按原课件归类保留，实际主逻辑或边界在逐图说明中注明。

## A 基本的数据逻辑

文字、词语或品牌字标直接成为视觉节点和关系载体。

## B 统计图形与计算

词语网络、文字布局、气泡或词云；字号／面积是否量化必须明示。

## C 视觉编码

字重、位置、方向、字标和色彩组织语义，不自动代表词频。

## D 数据／信息架构

主题词、类群、词项、关系与释义。

## E 视觉叙事架构

可以从中心词扩散，也可通过熟悉的词标进入群组。

## 从本组案例归纳的方法与边界

P032-I01 是词语节点网络，P032-I02 是品牌字标集合；二者均不是已确认的 A—Z 字母表。

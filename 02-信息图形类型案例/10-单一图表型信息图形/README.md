# 单一图表型信息图形（Single Chart）

本文件夹收录 2 张用户课件原图及 2 篇同编号说明文档。更新日期：2026-11-20。案例按原课件归类保留，实际主逻辑或边界在逐图说明中注明。

## A 基本的数据逻辑

用一个主要图形关系承担核心比较，允许辅有必要图例或小信息。

## B 统计图形与计算

主条形、轮廓比较或统一阵列；核对基线、比例与单位。

## C 视觉编码

长度、位置、轮廓或符号给主关系；装饰不破坏可比性。

## D 数据／信息架构

主题、主图、对象标签、读法与来源。

## E 视觉叙事架构

先看主比较，再通过标签和补充数字理解细节。

## 从本组案例归纳的方法与边界

P031-I01 有辅助模块，P031-I02 是多对象阵列；单一是主图重心，不等于只有一个对象。

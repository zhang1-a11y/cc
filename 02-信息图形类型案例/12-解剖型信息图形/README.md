# 解剖型信息图形（Anatomical）

本文件夹收录 2 张用户课件原图及 2 篇同编号说明文档。更新日期：2026-11-20。案例按原课件归类保留，实际主逻辑或边界在逐图说明中注明。

## A 基本的数据逻辑

整体与内部部件、结构位置和局部功能构成说明对象。

## B 统计图形与计算

剖面、爆炸、部件引线和局部放大；与医学或工程实测图区别。

## C 视觉编码

线指部件，面区剖开区域，体表达空间，文字说明功能。

## D 数据／信息架构

整体总览、部件名称、局部细节与功能说明。

## E 视觉叙事架构

先整体后局部，再回到部件如何组成主体。

## 从本组案例归纳的方法与边界

两例均采用剖面与引线，但为机械／虚构设定；解剖式画法不保证现实科学准确。

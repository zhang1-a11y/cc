# 比较型信息图形（Comparison Infographics）

本文件夹收录 2 张用户课件原图及 2 篇同编号说明文档。更新日期：2026-11-20。案例按原课件归类保留，实际主逻辑或边界在逐图说明中注明。

## A 基本的数据逻辑

两个或多个对象在共享属性与口径下比较。

## B 统计图形与计算

配对条形、镜像图、比例及数值；共享比较尺度并注明年份和单位。

## C 视觉编码

颜色与左右位置固定对象，条目对齐，照片不代替统计。

## D 数据／信息架构

对象身份、共同指标、辅助解释与来源。

## E 视觉叙事架构

先建立比较对象，再逐指标寻找差异和例外。

## 从本组案例归纳的方法与边界

时期对照与运动员对照都依赖同字段配对；跨量纲不比较条长，历史数据不作为现状。

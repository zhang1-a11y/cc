# 三维信息图形（3D Infographics）

本文件夹收录 2 张用户课件原图及 2 篇同编号说明文档。更新日期：2026-11-20。案例按原课件归类保留，实际主逻辑或边界在逐图说明中注明。

## A 基本的数据逻辑

立体或等距方式表现空间、组成与功能关系，三维是表现手段。

## B 统计图形与计算

分层、爆炸、剖面与等距示意；体积若未标尺不用于数量比较。

## C 视觉编码

点线面体与遮挡建立空间，颜色与物象解释功能。

## D 数据／信息架构

整体模型、层级／区域、引线说明及局部细节。

## E 视觉叙事架构

从整体进入分层场景，再理解功能之间的关系。

## 从本组案例归纳的方法与边界

P038-I01 是概念空间说明；P038-I02 可见占位文案。立体效果不等于真实数据证据。

# 信息图形类型与案例

本目录按**表现类型**编排；与 01 的**数据关系**正交。同一作品可同时采用混合型、列表型和时间轴的局部组件。每个类型文档先给出分析方法，案例原图到位后再补基于画面的观察。

| 类型 | 定义与分析入口 | 可对应的数据逻辑 |
| --- | --- | --- |
| 混合型（Mixed Charts） | [统计图与符号、说明文字共同叙事](01-混合型信息图形.md) | 编年、层级、编目、地理等 |
| 文字／列表型（Informational / List Infographics） | [条目和信息层级组织阅读](02-文字列表型信息图形.md) | 编目、字母表、层级等 |
| 时间轴型（Timeline Infographics） | [沿时间位置组织事件与状态](03-时间轴型信息图形.md) | 主要为编年，也可嵌入其他逻辑 |

[案例登记与更新规范](案例登记与更新规范.md)规定案例图、来源、分析记录与跨目录同步方式。[案例记录模板](案例/README.md)用于新增具体图像记录。当前没有本主题案例原图，故没有以作品名命名的分析文件；空白模板不是案例证据。

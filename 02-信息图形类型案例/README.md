# 常用信息图形类型案例库

本文件夹保留课件原有16个常用类型，并按用户要求增加第17类词云型，共17个类型子文件夹，另设一个独立的跨类型基础设计方法标签 ISOTYPE（不计入类型数量）。每类直接保存原图、已有同编号 Markdown 和 README 类型说明。当前共 **68张原图、39篇逐图说明**：36张来自原73页课件，30张为独立用户图片C001—C030，2张为外部词云参考W001、W002。C002—C030共29张按用户要求仅归档原图，未写分析。另附1份C001数据Excel。

## 基础设计方法标签（独立于类型）

- [00-ISOTYPE](00-ISOTYPE/README.md)：通过标准化图形符号、等值单位重复与系统化排列转译信息。它是跨类型的基础设计方法，而非第18种信息图形类型。已有相关案例保留原归档位置，由本标签交叉引用。

## 图文对应规则

- 完整分析一图一文，共用稳定编号，例如 `P024-I01.jpg` 与 `P024-I01.md`；P 表示课件实际页序，I 表示该页提取图编号。
- 同一类型的多个案例直接放在本类型文件夹；不再分别建立图片与说明子目录。
- README 给出类型概念、A—E 方法、案例索引和本组比较；每篇案例文档嵌入对应原图并记录来源与边界。
- 前三类原详细方法保存在各自子文件夹的 `类型说明.md`；根级旧入口保留导航，保证原链接可用。
- 01 只保存五篇文字定义，通过文本链接连接本目录内的具体案例，不嵌入图片。

## 分类与证据

按原课件归类便于追溯；同一张图的主数据逻辑可能与课件类型标签不同。层级型文件夹中的丝带图与芬兰熊地图、编年编目混合型中的网络威胁版式均在说明中列出分类边界。不会为迎合文件夹名称虚构父子关系或时间轴。

已有39篇逐图说明记录可见结构、A—E分析和未知项；另29张仅归档图片不作同等完成声明。原作作者、数据原始出处、未辨清数值不补造。不同版式未必是独立作品或独立数据证据，图像文件数不等同于独立研究数。

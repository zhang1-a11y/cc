# 时间轴型信息图形（Timeline Infographics）

本文件夹收录 2 张用户课件原图及 2 篇同编号说明文档。更新日期：2026-11-20。案例按原课件归类保留，实际主逻辑或边界在逐图说明中注明。

## A 基本的数据逻辑

事件或状态以时间键为主要组织关系。

## B 统计图形与计算

事件轴、环形时间线、阶段带；区分顺序示意与真实时距。

## C 视觉编码

节点、轨道、刻度与日期对应；插画负责识别事件。

## D 数据／信息架构

总时间范围、阶段、节点、注释与来源分层。

## E 视觉叙事架构

沿时间发展阅读，并可下钻局部。

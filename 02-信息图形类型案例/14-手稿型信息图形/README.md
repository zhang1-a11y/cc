# 手稿型信息图形（Manuscript Infographics）

本文件夹收录 2 张用户课件原图及 2 篇同编号说明文档。更新日期：2026-11-20。案例按原课件归类保留，实际主逻辑或边界在逐图说明中注明。

## A 基本的数据逻辑

以手绘线条和注释组织空间、对象或知识，属于表现风格维度。

## B 统计图形与计算

手绘剖面、知识图、方向示意；真实量尺须另核对。

## C 视觉编码

线条、纹理、色笔和手写字服务分组与定位。

## D 数据／信息架构

整体图像与局部标注组织多层细节。

## E 视觉叙事架构

先总貌，再允许读者探索局部。

## 从本组案例归纳的方法与边界

建筑与航海案例主数据关系不同；手稿风格不能取代信息分类、读法和来源。

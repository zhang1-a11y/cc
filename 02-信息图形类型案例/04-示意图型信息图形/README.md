# 示意图型信息图形（How-to Infographics）

本文件夹收录 2 张用户课件原图及 2 篇同编号说明文档。更新日期：2026-11-20。案例按原课件归类保留，实际主逻辑或边界在逐图说明中注明。

## A 基本的数据逻辑

操作对象、组成部件、条件与动作关系帮助读者理解怎么做。

## B 统计图形与计算

步骤示意、爆炸图、配料表；数量与时长只有标明时才读取。

## C 视觉编码

物象、引线、分层面与箭头各司其职，空间次序不自动等于操作次序。

## D 数据／信息架构

材料／条件、主体示意、操作说明与完成状态。

## E 视觉叙事架构

从准备和对象识别进入组合／操作，再交代结果。

## 从本组案例归纳的方法与边界

两份食物分解图均能解释食材，三明治图说明层次，拌饭图还叠加制作与食用信息。

# 图片式信息图形（Photo-graphic Infographics）

本文件夹收录 2 张用户课件原图及 2 篇同编号说明文档。更新日期：2026-11-20。案例按原课件归类保留，实际主逻辑或边界在逐图说明中注明。

## A 基本的数据逻辑

实景照片与数据、标签或解释性图形共同表达信息。

## B 统计图形与计算

照片叠加数值、柱形和局部图解；数值遵守原有基线和分母。

## C 视觉编码

照片提供对象／情境，图形提供定量或关系，文字给口径。

## D 数据／信息架构

主题照片、重点数据、分区细节与来源相互对应。

## E 视觉叙事架构

以情境吸引读者，再进入数据解释或规划信息。

## 从本组案例归纳的方法与边界

照片进入图表不意味着可任意裁切计量长度；现实照片与未来效果表达须区别。

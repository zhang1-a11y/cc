# 可视化简历（Visual Resume）

本文件夹收录 2 张用户课件原图及 2 篇同编号说明文档。更新日期：2026-11-20。案例按原课件归类保留，实际主逻辑或边界在逐图说明中注明。

## A 基本的数据逻辑

身份、经历、教育、技能与联系信息构成个人资料集合。

## B 统计图形与计算

经历年表、技能条目或矩阵；主观自述不得伪装为统一测量。

## C 视觉编码

标题、肖像、框线、图标和时间位置服务招聘扫描。

## D 数据／信息架构

身份概要、经历、教育、能力与联系入口。

## E 视觉叙事架构

允许按招聘问题跳读，并按年份查阅经历。

## 从本组案例归纳的方法与边界

两例风格不同但资料字段相似；装饰性软件图标不能直接换成能力百分比。

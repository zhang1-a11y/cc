# 层级型信息图形（Hierarchical Infographics）

本文件夹收录 4 张用户课件原图及 4 篇同编号说明文档。更新日期：2026-11-20。案例按原课件归类保留，实际主逻辑或边界在逐图说明中注明。

## A 基本的数据逻辑

结构型表现父子分支、包含与从属；等级型表现有依据的次序。

## B 统计图形与计算

树状图、分支带、嵌套或等级图；宽度与面积只有经标定才计量。

## C 视觉编码

连接与包围表达从属，层级与时间可叠加；装饰高低不作为结构证据。

## D 数据／信息架构

根／总体、主分支、细节点与必要背景。

## E 视觉叙事架构

可由总体深入，也可从叶节点回溯；等级排序另交代排序依据。

## 从本组案例归纳的方法与边界

P006-I01、P008-I01 存在分支；P030-I01 的丝带与 P030-I02 的地图作为课件归类边界保留。

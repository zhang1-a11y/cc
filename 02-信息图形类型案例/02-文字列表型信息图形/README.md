# 文字列表型信息图形（Informational / List Infographics）

本文件夹收录 2 张用户课件原图及 2 篇同编号说明文档。更新日期：2026-11-20。案例按原课件归类保留，实际主逻辑或边界在逐图说明中注明。

## A 基本的数据逻辑

文字解释、并列条目、清单或知识模块组成信息主体。

## B 统计图形与计算

可采用列表和小图表；没有数值统计时如实说明，不强加计算。

## C 视觉编码

字重、字号、分栏、符号与留白承担层级；编号含义须辨清。

## D 数据／信息架构

标题、分组、条目、解释和来源组织为可扫描结构。

## E 视觉叙事架构

允许跳读，也可由中心物象进入周边文字。

## 从本组案例归纳的方法与边界

P023-I01 是文字主导版式，P023-I02 包含主题知识模块；文字型不一定是编号清单。

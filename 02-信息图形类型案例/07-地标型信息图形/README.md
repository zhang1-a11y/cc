# 地标型信息图形（Location Infographics）

本文件夹收录 2 张用户课件原图及 2 篇同编号说明文档。更新日期：2026-11-20。案例按原课件归类保留，实际主逻辑或边界在逐图说明中注明。

## A 基本的数据逻辑

地点、路线、站点与空间关系构成定位或导航任务。

## B 统计图形与计算

地理底图、拓扑线网、路线、局部放大；真实坐标与示意长度分开。

## C 视觉编码

点为位置或站点，线为路径，色彩与符号辅助识别。

## D 数据／信息架构

整体范围、地点／路径、局部说明及图例。

## E 视觉叙事架构

可以沿路径叙事，也可以按起点和终点检索。

## 从本组案例归纳的方法与边界

P028-I01 侧重旅程故事，P028-I02 侧重线路检索；地图不都采用同一种阅读路径。

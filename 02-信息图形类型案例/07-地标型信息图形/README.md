# 地标型信息图形（Location Infographics）

本文件夹收录 **3张原图与3篇同编号案例说明**：2张来自用户课件，1张为独立用户图片C001；另附C001数据Excel。更新日期：2026-11-20。

## 与01五类的关系

本类型通常对应01的**地理图形**主逻辑，但归档前仍需判断地图是否承担真实位置、拓扑或空间属性。以C001为例：主逻辑为地理，营收排序为辅助关系；02主标签为地标型，混合型与比较型只作交叉引用。

## A 基本的数据逻辑

地点、路线、站点与空间属性构成定位、导航或地区比较任务。既可以问“如何到达”，也可以问“哪些地点的同口径指标更大”。数据对象与地理标识必须对应；画面上的引导线不自动代表路线。

## B 统计图形与计算

使用地理底图、点位、拓扑线网、路线、局部放大或地点属性符号。真实坐标与示意长度分开。地点总量可以由圆符号表示；若声明按面积计量，半径与量值平方根成正比。C001原图的精确尺寸函数未知，不能把它写成已确认的面积比例。

## C 视觉编码

| 元素 | 可承担的语义 | 必须区分 |
| --- | --- | --- |
| 点 | 位置、站点或存在 | 一点一个地点与一点若干对象不同 |
| 线 | 路线、拓扑连接或标签引导线 | 对应、流向和父子关系不同 |
| 圆大小 | 地点指标规模 | 直径映射与面积映射不同 |
| 地理区域 | 范围或底图背景 | 区域底色与数值设色不同 |
| 文字 | 地名、精确值与口径 | 精读标签不能被地图装饰替代 |

## D 数据／信息架构

整体范围、地点／路径、地区指标、局部说明、图例与出处分层。密集地点可保留地理锚点，把大圆和标签移到图外，用同一geo_id关联的引导线连接；布局坐标与地理坐标分别保存。C001展示了这种“位置与规模分开、身份仍然关联”的组织方法。

## E 视觉叙事架构

路线题材可以沿路径展开，线路题材可以按起终点检索，地点属性题材可以从重点城市进入空间比较。C001通过纽约主角、其他城市对照、地图定位、迁址个例与科技三城合计形成编排；跨城合计改变了比较单元，须显式说明。

## 从本组案例归纳的方法与边界

- P028-I01侧重旅程故事，P028-I02侧重线路检索，C001侧重都市区的地理位置与营收规模。
- 地标型不只限于导航；地点属性比较也是适用范围。该扩展来自C001的可见构造与数据粒度。
- C001的地图小点不是企业数量；连接线不是资金流；底图透视不是三维营收编码。
- 以面积为量尺时仍按平方根半径计算。原图量尺不明与建议重制量尺必须分别写明。
- 地点密集时外置符号能减轻遮挡，但会增加引导线追踪成本；必要时配合表格、编号或分面。

# 混合型信息图形（Mixed Charts）

> 课件来源：PDF 第 22、36—37、58—61 页。文字分类与方法已对照；具体作品画面的图表、配色、数值和符号尚待核验。参见[来源记录](PDF对照与案例索引.md#mixed)。

## 定义与边界

本仓库按用户要求，将统计图形与文字、象形符号、图解或场景共同编码并承担视觉叙事的作品作为混合型研究对象。可以是一种统计图经过语义与叙事转换，也可以是多种图表共同解释同一主题；不以“必须有两种以上统计图”作为门槛。

与单纯读出数值的图表相比，分析重点增加了“符号如何解释对象、组件如何组织故事、读者如何建立理解”。这与数据可视化存在交集，统计准确性要求仍然保留。把几张互不相关的图拼在一页，或给图表附加装饰图标，尚不足以形成有逻辑的混合叙事。

课件第 36—37 页明确标注“编年图＋编目混合图”，说明数据逻辑也可以混合。数据逻辑的混合与表现组件的混合应分别登记。

## A 基本的数据逻辑

先把主题拆成可回答的问题：规模、构成、变化、分类、位置、关系或流程。每个模块连接自己的数据表，并通过对象 ID、时间、类别或地理键关联，不能只靠相似配色暗示关系。

一份可用的数据结构包括：对象表、指标表、必要的事件／地点表，以及模块说明。每条指标保留值、单位、分母、时期和出处；每个模块注明要回答的问题。关联逻辑见[编年](../01-信息图形数据逻辑/01-编年型信息图形概念定义.md)、[层级](../01-信息图形数据逻辑/02-层级型信息图形概念定义.md)、[编目](../01-信息图形数据逻辑/03-编目型信息图形概念定义.md)、[字母表](../01-信息图形数据逻辑/04-字母表型信息图形概念定义.md)、[地理](../01-信息图形数据逻辑/05-地理图形信息图形概念定义.md)。

## B 统计图形与计算方式

| 子问题 | 统计或图解方法 | 保留的约束 |
| --- | --- | --- |
| 数量比较 | 条形、点图、单位符号阵列 | 统一单位、比较尺度和必要基线 |
| 部分与总体 | 构成条、环形图、单位阵列 | 类别能否相加、分母是什么 |
| 变化与阶段 | 折线、时间轴、区间条 | 时间精度、真实时距或顺序示意 |
| 空间与流向 | 地图、流线、路径图 | 空间单元、归一化、方向与线宽单位 |
| 关系与步骤 | 节点连接、流程示意 | 连接语义；没有量值就不虚造统计 |

跨图比较须统一对象、时期与统计口径。符号重复计量时，若每枚代表 k 个单位，则符号数 n = 数值 v／k；v 不能整除 k 时，可用有说明的部分符号或标注原值，不无说明四舍五入。此为方法说明，不是从课件案例读取的数值。

## C 视觉编码：符号、ISOTYPE 与图表

结合 PDF 第 58 页，用户所说“ISO 图形”在本课语境中按 **ISOTYPE** 理解，即 International System of Typographic Picture Education。它与 ISO 公共信息标识标准不是同一个概念，不能把任意图标称为符合 ISO 标准或 ISOTYPE 历史作品。

| 视觉元素 | 承担的功能 | 优化方式 |
| --- | --- | --- |
| 点 | 个体、观测、节点 | 标出单位；避免重叠造成漏读 |
| 线 | 关系、时间路径、趋势、流量 | 不同语义用线型或标签区分；线宽计量需图例 |
| 面 | 构成、类别容器、区域 | 区分“分组背景”和“面积计量” |
| 体 | 空间结构或叙事插画 | 非量化体积不用于数值比较，避免透视遮挡 |
| 符号 | 对象语义或重复计量单位 | 同对象同符号；重复单位保持同尺度 |
| 色彩 | 类别、数值或强调 | 跨模块语义一致，配合文字和形状 |
| 文字 | 标题、事实、解释和来源 | 分层排布，区分事实与评论 |

ISOTYPE 的方法重点包含用重复的单位符号呈现统计量。符号大小一般保持稳定，通过数量显示增减；若另用符号面积编码，则明确属于另一种映射，并给出尺度。符号可以帮助理解，但不能替代分母、单位和来源。

补充来源：[University of Reading 的 ISOTYPE 说明](https://isotyperevisited.org/1981/01/isotype-and-the-university-of-reading.php)，访问日期 2026-11-19；该来源用于术语与重复单位原则核对，不证明课件某幅作品的流派归属。

## D 数据／信息架构

按“主题问题 → 数据概览 → 分问题模块 → 局部细节 → 口径与来源”组织内容。数据层负责事实与关联，信息层负责筛选与分组，表现层负责图表和符号。每个模块能独立解释，同时共享必要的视觉词典和导航。

跨模块保留对象 ID 和来源；同一数字多次出现时核对版本，避免一个总量被不同模块分别改写。相关课件依据为第 43、69—70 页，详见[共同方法](PDF对照与案例索引.md#methods)。

## E 视觉叙事架构

以读者的问题建立入口，再选择“总量 → 分解 → 变化 → 情境解释”等路径。主图提供核心证据，辅助图回答原因线索或背景，图标连接抽象数字与具体对象；不得凭相关或先后关系直接断言因果。

标题、模块尺度、编号和局部强调引导节奏。叙事可以有主线，也应允许读者进入细节并返回概览；结论可追溯到实际数据，行动建议与观察事实分开。

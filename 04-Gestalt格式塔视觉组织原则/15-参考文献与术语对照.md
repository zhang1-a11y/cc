## 术语与本库用法

| 英文 | 本库中文 | 容易混淆之处 |
| --- | --- | --- |
| Gestalt | 格式塔 | 是研究传统与整体组织概念，不是一种统计图表 |
| Perceptual grouping | 知觉分组 | 视觉上的归组不保证数据关系真实 |
| Proximity | 接近／邻近 | 关注相对距离，不是固定间距规范 |
| Similarity | 相似 | 颜色、形状、大小是实现维度 |
| Good continuation | 良好连续 | 不等于把真实折线任意平滑 |
| Closure | 闭合 | 不等于共同区域，也不能补造数据 |
| Common region | 共同区域 | 关注同处一个有边界的区域 |
| Element connectedness | 元素连接 | 关注元素通过连接被组织在一起 |
| Uniform connectedness | 均匀连接性 | 关注属性均一的连续区域形成视觉单元 |
| Common fate | 共同命运 | 关注协调运动或变化 |
| Synchrony | 同步 | 关注变化发生的时间一致 |
| Symmetry | 对称 | 不等于数值相等、观点同权或一般均衡 |
| Parallelism | 平行 | 不等于统计相关 |
| Figure–ground organization | 图底组织 | 关注图与底及边界归属 |
| Prägnanz / Good Gestalt | 简洁与良好形态 | 总括原则，不等于极简主义 |

中文译名可能存在差异。新增案例时同时登记英文名与本库ID，避免同义异译产生重复档案。

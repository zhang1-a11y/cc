## 1. Gestalt是什么

Gestalt通常译为“格式塔”，关注视觉输入如何被组织成可感知的整体、分组、轮廓以及图形与背景。理解一幅信息图形时，读者不仅逐个识别点、线和文字，也会依据它们之间的关系形成组织。[S08]

本目录研究这些知觉组织方式如何参与信息图形设计。它与仓库现有部分的分工如下：

| 目录 | 主要问题 | 与04的关系 |
| --- | --- | --- |
| 01-信息图形数据逻辑 | 数据本身是什么关系 | 先确定真实的数据逻辑，04再帮助呈现关系 |
| 02-信息图形类型案例 | 作品采用什么表现类型 | 04可以为同一作品提供多个原则标签 |
| 03-统计图形分析 | 采用什么统计与图表机制 | 04辅助组织图表，不代替尺度、统计与数据校验 |
| 04-Gestalt格式塔视觉组织原则 | 读者依据什么线索组织视觉元素 | 本目录 |
| 05及以后：具体的信息图形设计案例 | 如何综合应用数据、图表、编码与叙事 | 未来建立，具体名称按后续任务确定 |

04不作为五种数据逻辑之外的“第六种信息图形类型”，也不与统计图形类型混为一类。既有02类型案例保留原位置。

## 2. 到底一共有几条

**没有唯一、封闭、统一编号的总表。** 文献会依研究范围列出不同的原则，也会把同一种原则按颜色、形状等属性展开，或者把图底组织、总括原则与分组线索一起讨论。[S02][S03]

**本库第一版收录12个核心档案条目。** 这是服务信息图形研究的建档方案，不宣称“Gestalt一共只有12条”。其中前10项是具体分组、轮廓或形态线索；第11项是图底组织主题；第12项是总括原则。不同研究对具体线索的归属仍有交叉。[S02][S07]

| 编号 | 条目 | 英文 | 本库层级 |
| --- | --- | --- | --- |
| G01 | 接近原则 | Proximity | 经典分组线索 |
| G02 | 相似原则 | Similarity | 经典分组线索 |
| G03 | 良好连续原则 | Good Continuation | 经典分组与轮廓线索 |
| G04 | 闭合原则 | Closure | 经典轮廓与形态组织线索 |
| G05 | 共同区域原则 | Common Region | 后续研究提出的分组线索 |
| G06 | 连接原则 | Connectedness | 连接与视觉单元形成；本库合并设为一个档案主题 |
| G07 | 共同命运原则 | Common Fate | 经典动态分组线索 |
| G08 | 同步原则 | Synchrony | 后续研究提出的动态分组线索 |
| G09 | 对称原则 | Symmetry | 分组及图底组织都可能涉及的形态线索 |
| G10 | 平行原则 | Parallelism | 经典形态组织线索 |
| G11 | 图底组织 | Figure–Ground Organization | 视觉组织主题，通常不作为普通分组法则同层计数 |
| G12 | 简洁与良好形态原则 | Prägnanz / Good Gestalt | 总括性的知觉组织原则 |

计数边界：连接一篇中辨析“元素连接”与“均匀连接性”，不将两者等同；对称、闭合、平行也可能参与图底组织。补充文档保留既往经验、注意、凸性等因素以及涌现、补全、多稳态、不变性等相关概念，后续按用途扩展。

## 3. 原则如何使用

以下是本库采用的设计工作方法，不是文献中的统一操作规程。

1. 明确读者需要完成的任务：查找、配对、比较、追踪还是理解层级。
2. 核对真实关系：哪些元素属于一组、哪些只是相邻、哪些存在连接。
3. 选择能表达该关系的主要线索，再用必要的辅助线索强化。
4. 说明读者可能如何解释画面，并检查是否引入假分组、假连接或假连续。
5. 用具体任务检验，记录原稿、修改稿、参与者与条件、错误和结果。
6. 将实测结果、设计判断和未验证建议分别记录。

原则可能相互增强，也可能冲突；不建立“连接永远大于区域、区域永远大于距离”等脱离条件的固定排序。[S03]

## 4. 每篇原则文档的固定内容

| 模块 | 必须回答的问题 |
| --- | --- |
| A 定义与术语 | 原则是什么？有哪些英文名和中文异译？ |
| B 概念边界 | 与相邻概念有什么区别？不能据它推断什么？ |
| C 示例与案例 | 画面中哪些元素、关系和位置能作为证据？ |
| D 设计分析 | 数据关系如何转成视觉线索？可能怎样影响阅读？ |
| E 实践建议与检验 | 应改什么、保持什么，怎样评价结果？ |
| F 来源与关联 | 定义依据是什么？与哪些原则、01/02/03内容有关？ |

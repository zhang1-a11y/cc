# 案例统计图形判读与复现模板

## 工作顺序（用于02案例的B/C分析）

1. 先提出读图问题，并区分01主数据逻辑、02表现类型与基础设计方法。原图分类是观察线索，不是统计图形已被识别的证据。
2. 按每个图形模块分别描述可见标记：点、线、条、区域、颜色、符号、标签、刻度、图例。记录直接可见证据及其位置。
3. 逆向构建最小数据表：每行代表什么实体或观测？主键、粒度、单位、时间、地理范围、分母是什么？原图不提供时标未知。
4. 判断统计变换：保留个体、分组求和/计数/均值、分位数、分箱、密度、堆叠、归一化、排名、层级汇总或边聚合。
5. 查本库同类图表的 dimensions/mapping/render；填字段绑定、默认聚合与量尺。注明这仅是可行的重建机制，不代表原作使用 RAWGraphs。
6. 选择软件或代码重建，以已知值核验标记数、长度、面积、比例、坐标、缺失。保存项目、参数、原数据与来源；无原数据时仅作示意性重建。
7. 回接02的D信息架构和E视觉叙事：统计关系怎样支持读者任务？阅读顺序、标题强调、图例与来源是否完备？

## 可复制记录表

| 字段 | 填写规则 |
| --- | --- |
| 原图及来源 | 编号、链接、版本、作者/数据出处（未知则明确） |
| 图形组件、读图任务 | 比较/分布/趋势/构成/关联/层级等；可有多个 |
| 对象和数据粒度 | 每行定义、主键、字段类型、含义、量纲、分母 |
| 转换前后结构 | 长宽表/样本表/层级路径/边表，示例记录 |
| 算法及参数 | group keys、聚合、排序、分箱、缺失、归一化 |
| 映射 | 字段→通道→量尺→图例；标记无数据语义的装饰 |
| 证据及未知 | 可见观察、来源核实、机制推断、待证参数分开 |
| 制作及复核 | 选择图表、映射、选项、输出、验证和局限 |

## 推理实例：同一数据的三种结构和图形（人工示例，不是历史数据）

| 年份 | 类别 | 数量 |
| --- | --- | ---: |
| 2024 | A | 20 |
| 2024 | B | 30 |
| 2025 | A | 35 |
| 2025 | B | 15 |

- 折线：X=年份，Y=数量，Lines=类别，按年份和类别聚合；目标是观察变化。
- 分组条形/堆叠条形：转为宽表（年份,A,B），2024,20,30；2025,35,15。Sets/X=年份，Size=A、B。并排比较各类别，堆叠比较整体及构成；两年总量均50，但构成不同。
- ISOTYPE（非RAWGraphs内置图表）：若一枚符号=5单位，则A、B分别为4、6和7、3枚；须独立核对量尺和整数规则。见[05-ISOTYPE 设计方法](../05-ISOTYPE/README.md)。

## 独立依赖：Calendar heatmap

应用的 charts.js 注册 calendarHeatmap，package.json 声明独立依赖。一般日历热图以日期定位日期单元，颜色表达聚合量或状态；同日多记录、缺失与零、时区及周起点都需明确。此为通用分析，未取得独立实现，字段、默认聚合、具体布局及选项待核对，不能与已审读31模块同等处理。

## 常见反例

- 图上大图标不必然是面积比例；长宽各放大两倍会使面积放大四倍。
- 不规则单元既可能是Voronoi邻近分区，也可能是加权层级树图或真实地域；必须看数据键和生成过程。
- 连接线可能是趋势、边关系、层级关系或仅为注释引线，不能自动判定因果或路径。
- 复现的统计正确性优先于外观相似；不能从图像猜补数据后将其标为原始数据。

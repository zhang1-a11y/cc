## 与本库01、02的联系

01 数据逻辑回答数据如何组织，02 表现类型回答信息如何呈现（ISOTYPE 为跨类型设计方法），03 统计图形回答数据怎样通过统计和几何转译为图形。图形可服务多种逻辑：时间折线通常用于编年，层级树图用于层级，条形图常用于编目；地理主逻辑需具备地理键或坐标，不能仅凭图形像地图判定。单图可同时使用多个统计机制。

研究分类是依任务与算法归组，非 RAWGraphs 自身唯一分类。若案例使用非内置图形（地图投影、ISOTYPE单位图、词云等），应另核实算法，不强行套用本库。
